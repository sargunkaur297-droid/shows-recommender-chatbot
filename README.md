# 🎬 Shows Recommender Chatbot

An AI-powered chatbot that recommends movies and TV shows based on user preferences. The chatbot provides personalized recommendations through natural language conversations, making it easy for users to discover new entertainment.

## ✨ Features

- 🤖 AI-powered conversational interface
- 🎥 Movie and TV show recommendations
- 💬 Natural language interaction
- ⚡ Fast responses using Mistral AI
- 🎨 Simple and user-friendly Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Mistral AI
- python-dotenv


## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/shows-recommender-chatbot.git
```

2. Navigate to the project folder

```bash
cd shows-recommender-chatbot
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

4. Create a `.env` file and add your Mistral API key

```env
MISTRAL_API_KEY=your_api_key_here
```

5. Run the application

```bash
streamlit run uichatbot.py
```
