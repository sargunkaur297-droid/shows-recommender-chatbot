# 🎬 Shows Recommender Chatbot

An AI-powered chatbot that recommends movies and TV shows based on user preferences. The chatbot provides personalized recommendations through natural language conversations, making it easy for users to discover new entertainment.

## ✨ Features

- 🤖 AI-powered conversational interface
- 🎥 Movie and TV show recommendations
- 💬 Natural language interaction
- ⚡ Fast responses using Mistral AI
- 🎨 Simple and user-friendly Streamlit interface

## 🛠️ Tech Stack

- Python
- Streamlit
- LangChain
- Mistral AI
- python-dotenv
